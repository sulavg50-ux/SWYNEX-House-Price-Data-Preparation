In creating this dataset I have made the following assumptions:

Filled in the numeric variables using the median so that they are not skewed by extreme values.



Filled in the categorical variables by filling them with the most common value.

Removed all duplicates.

Kept the original variable names and tried to include the correct data types.

Did not remove any outliers as there could be true high/low values for house prices.

Left the original dataset as is and put the cleaned version into a new CSV file.



The dataset is now ready for further analysis and machine learning.
